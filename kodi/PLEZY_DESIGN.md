# Plezy design conventions for script.plezy.native

How the add-on's Kodi skin maps the official Plezy app (edde746/plezy, TV layout) onto Kodi. Every screen follows
these rules so they look like one app. Source references are relative to the Plezy repository.

## Scale and typography

- **TV-scaled Plezy values** (anything multiplied by `TvLayoutConstants.scaleOf`, e.g. home, detail screens,
  rails, spotlight): **1:1** at 1080p. Plezy on Linux runs TV mode at device-pixel-ratio 1, so this is what the
  app looks like on the same box.
- **Unscaled Plezy chrome** (player controls, sheets, dialogs, menus, settings rows): **x1.5** geometry, so Kodi's
  larger fonts fit; corner radii 1:1 to x1.5 using the closest texture below.
- Kodi fonts are fixed (Estuary names): `font10` (~24px), `font12`, `font13`, `font14`, `font20_title` (bold),
  `font32_title` (bold), `font45`, `font60`. Mapping from Plezy sizes after scaling: <=13px -> font10,
  14-16 -> font12, 17-18 -> font13, 19-22 -> font14, 24-30 bold -> font20_title, 32-44 -> font32_title/font45,
  54+ -> font60. `[B]..[/B]` for w600+. Grow containers to fit Kodi text; never shrink text.
- Sentence case. Drop `[UPPERCASE]` from labels on Plezy-styled screens.
- Vertical values always go through `vscale` (`{{ vscale(120) }}`, `{{ (ch + 10)|vscale }}`, `{{ ch|vscale }}`).

## Colour tokens

`core.plezy.*` in `lib/templating/context.py` (Plezy dark theme, AARRGGBB). Never hard-code greys or accents:
bg, surface, text, muted (60%), subtle (54%), summary (78%), faint (40%), disabled (38%), outline, focus_fill
(12%), selected_fill (10%), selected_focus_fill (15%), track, scrim, on_primary, tonal (surface @38%), tile,
focus_bg (white @20%), menu_surface, input_fill, input_focus_fill, chip_selected_focus, chrome_idle,
chrome_focus, shadow, dialog_scrim, sheet_scrim, error, player_fg, player_fg_muted, player_fg_subtle,
player_track, player_buffer, player_card, player_tooltip, active (amber, active player toggles).

## Focus language

- **Cards** (artwork): 2.5px (3px) outside ring in `text` + soft glow beneath + 1.03 zoom. `plezy/ring-8.png`
  (border 11) drawn 3px outside the artwork, `plezy/glow.png` (border 48) 40px outside, beneath the artwork.
- **Rows / list tiles / menu items**: fill only. Focused `focus_fill`, selected `selected_fill`, focused+selected
  `selected_focus_fill`. Text stays `text`. Never PM4K's white row with black text.
- **Buttons**: primary = white (`text`) stadium with `on_primary` label on focus; idle = `tonal` with `text`
  glyph. Detail action rows use `includes/plezy_action_button.xml.tpl`. Player transport uses the "plezy" button
  theme (white disc, dark glyph on focus) with a 1.12 zoom.
- **Round chrome over artwork** (home/search/back): `chrome_idle` disc, `chrome_focus` + ring on focus
  (see `default.xml.tpl`).
- Rows that are not active dim (fade to ~45-60%); rows scrolled past fade out (see the home template).

## Textures (media/script.plex/plezy, generated by tools/make_plezy_textures.py)

- Rounded rects `r6 r8 r12 r14 r16 r20 r24 r28 r30 r32` (border = radius), `r12-top`, `r12-bottom` (border 12).
- Pills `pill-40/48/56/64` (border = height/2); split segments `split-l-56` (border 28,28,8,28), `split-r-56`.
- M3E grouped rows `group-top/mid/bottom/single` (44x44, border 20).
- Rings: `ring-8`, `ring-12` (cards), `ring-pill-48/56/64` (border = height/2 + 3, drawn 4px outside),
  `ring-circle` (208x208 around a 200 circle at -4,-4), inside strokes `outline-pill-64`, `focus-pill-64`
  (border 33), `outline-r8` (border 8).
- `circle` (128), `mask-circle` (200), `glow`, `glow-circle` (280, at -40,-40), `panel-right-32`, `spinner`,
  `qr-plex-link` (240), scrims `scrim-h`, `scrim-v`, `scrim-bottom`, `scrim-top` (black .70 -> 0; flipy for the
  bottom), `scrim-strip`.
- Masks (diffuse, exact on-screen size): `mask-poster` 200x300, `mask-wide` 400x225, `mask-square` 200x200,
  `mask-grid-*`, `mask-rail-poster` 174x261, `mask-rail-square` 174x174, `mask-rail-wide` 296x167, `mask-strip`
  240x136 r12, `mask-bif` 320x180 r12, `mask-cover-270` r30, `mask-np-600(-paused)`, `mask-np-688(-paused)`,
  `mask-list-poster` 128x192 r12, `mask-list-square` 128x128 r12, `mask-row-square` 96x96 r9, `mask-row-wide`
  171x96 r9.
- Icons `icons/<Material Symbols name>.png` (white, 96px, filled, weight 700), plus named ones
  (`hub_*`, `movie`, `show`, ...). Outline variants: `radio_button_unchecked`, `check_box_outline_blank`.
- Baked action buttons `action/<icon>.png` / `-focus.png` (circle), `pill-<icon>`, `label-<icon>`
  (border 64,28,28,28), `split-<icon>` (play_arrow, resume), `version`.
- Need more? Drop a JSON file into `tools/textures.d/` (`{"icons": [...], "action_icons": [...],
  "masks": {"name": [w, h, r]}, "rounded": [r]}`) and re-run the generator.

## Detail screens (pre-play, show, season)

Plezy TV detail (media_detail_screen.dart `_buildTvDetailScreen`): no poster; full-bleed backdrop with the
spotlight scrims; a bottom-aligned hero column; an action row; a rail of hubs anchored to the bottom.
- Hero column x=60, width 1092 (60% of the screen minus the margin). Clear logo slot 790x220 (aspect keep,
  left/bottom) ending at y~390; title fallback font45 [B] with `shadow`; optional line (episode or season
  title) font14 [B]; metadata line font13 [B] (`plezy_ui.detail_meta`); summary font12 in `summary`,
  3 lines; action row y~590, 56 tall, gap 10; track status right-aligned x 1176-1860 on the action row, font10
  muted.
- Rail below (~y 670+): `plezy_row_header` + `plezy_hub_card` rows at tallPosterScale .72: poster 174x261,
  person/square 174x174, wide 296x167; pitch card + 24; active row on top, next one peeks, others dim.
- `plezy_ui.detail_meta / season_meta / play_label / episode_label / abbreviated_date` build the text.

### What the wave-1 screens settled (reuse these patterns)

- Hero column = a vertical grouplist with `<align>right</align>` (bottom alignment; Kodi's GetAlignOffset) and
  `<height max=..>auto</height>` textboxes, so a missing logo or short summary lets the column sit lower, as in
  Plezy. Info-block focus fill = a twin grouplist clipped at the column foot plus a clipped r8 cap.
- Action rows are one grouplist of `plezy_action_button`s inside the group the Python calls 300 (so
  `ControlGroup(300).HasFocus(0)` keeps its meaning); Play "S1E3" uses shape `label`, movies/episodes use `pill`.
- Rails: `pre_play_rail_row.xml.tpl` / `episodes_rail_row.xml.tpl` = `plezy_row_header` + `plezy_hub_card` row of
  height ch + 136; each row's slide animation must equal its own height; rows above the active one fade out, rows
  below dim, the whole band dims while focus is above it. 4:3: vscale(1080) = 810, so use `plezy_scrims ... foot=True`.
- Python builds the text in Kodi-free modules (`lib/plezy_*.py`) with tests; focus handlers never touch the network.
- Plezy chrome that is not TV-scaled (player) is x1.5, bottom-anchored with `{{ vscale(1080 - y) }}r`; the player
  uses the "plezy" button theme art with a 1.12 zoom and `core.plezy.active` (amber) for active toggles.
- The preview tool understands these (auto width/height, bottom align, usecontrolcoords, alt textures, zoom).

## Verified Kodi behaviour (do not "fix")

- Navigation tags with conditions: Kodi uses the **first** matching numeric target (`CGUIAction::GetNavigation`);
  only builtin string actions all execute.
- `<scroll>Control.HasFocus(n)</scroll>`: a non-boolean value keeps Kodi's default (scroll while focused).
- Grouplists and lists clip to their bounds: keep focus rings/zoom inside the control (pad the item).
- `border` on a 10px white-square stretched texture is fine in Kodi.
